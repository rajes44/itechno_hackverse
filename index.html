Overview

What is HackVerse?

HackVerse is an intensive build challenge where teams create a fully functional website using HTML, CSS and JavaScript — within a fixed time window.

Participants are evaluated on technical execution, visual quality, and problem-solving under pressure. Only teams that meet the submission deadline will be judged.
